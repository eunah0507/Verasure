## 💡 Why Verasure?

**Verasure**는 라틴어 *Verus*(참된, 진실한)와 영어 *Sure*(확실한)를 결합한 이름입니다.

보험은 가입으로 끝나는 상품이 아니라 지속적으로 이해하고 관리해야 하는 금융 계약입니다.
하지만 대부분의 보험 정보 서비스는 사용자를 대신해 "이 보험이 좋다·나쁘다"를 판단해줍니다.
Verasure는 반대의 방향을 택했습니다 — **판단하지 않고, 확인 가능한 사실만을 정확하게 전달하는 것**을 원칙으로 삼았습니다.

이 원칙은 이름에도 그대로 담겨 있습니다.

- **Verus (참됨)** — 시스템이 만들어낸 그럴듯한 답이 아니라, 실제 보험증권에 존재하는 근거만을 바탕으로 답합니다.
  약관에 없는 내용을 생성하지 않는 RAG 설계, 추출 실패와 데이터 부재를 구분하는 Validation 로직이 여기에 해당합니다.
- **Sure (확실함)** — 확실하지 않은 것은 확실하지 않다고 말합니다.
  판별이 불가능하면 `UNKNOWN`으로 남기고, "미보유가 곧 문제는 아니다"라는 원칙을 명시하며,
  갱신 리스크 수치는 참고용임을 분명히 밝힙니다.

**Verus + Sure → Verasure**

확실히 아는 것만, 확실하게 전달합니다.
